# Ahmed Bouramdane — Portfolio

A responsive Next.js portfolio with a warm cream, yellow, and orange palette. Skills are grouped into six technical areas with technology icons. The page also uses a React Three Fiber sculpture, GSAP entrance and scroll reveals, and an interactive parametric drawing.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Configuration

Copy `.env.example` to `.env.local` when deploying:

- `NEXT_PUBLIC_SITE_URL` — the deployed origin, used for canonical metadata and the sitemap.
- `NEXT_PUBLIC_CONTACT_EMAIL` — an email address to enable the direct email link. No contact form or email delivery service is configured.

The project descriptions are based on public GitHub repository metadata and documentation; repository links point to the source of truth.
